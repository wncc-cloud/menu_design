Admin changes apply to the customer app live (items need Publish, like the real thing).

Pretend the world is…

Scenario presets (resets the session and reloads as a returning visit):
Tighter: no ingredients line, 1-line description, smaller gaps, photo-less items are text-only. Scroll down: the search bar tucks away, scroll up: it returns.
"New browser session" forgets that the promo was already shown. Café status takes effect on the next load / checkout.

Things to try

  1. Reload the app (↻) and watch splash → skeleton → menu → pop-ups.
  2. Tap chips, search, ADD / + / −, then the green cart bar → place an order.
  3. Admin → Sections: rename a special section, hide it, reorder, then go back to Customer.
  4. Admin → Items: toggle Chef flag / Allow note, Publish, check checkout.
  5. Admin → Promotions & pop-up: pick the ONE thing that opens on load (Nothing / a promotion / rotate / Chef Special / Best Sellers / any section) and how often. Note the “Live now / Not opening because…” line.
  6. Admin → Promotions: edit text (see counters), auto-dismiss, try a placeholder number, ＋ Add / duplicate / delete (max 4), watch the “Live now / Not live: …” chips.
  7. Choose Nothing: nothing pops up. Choose a promotion: only that opens (even if Chef Special exists). Choose a section that is hidden or empty: nothing opens and the page says why.
  8. Set café Closed, reload: see closed-mode card.
  9. Use the scenario presets and read the “Why this happens (live)” panel: it lists every check (✔/✖), which pop-up wins, which promo is picked, and which UI parts are on.
  10. Set a promo's end date before “Today's date”, or move today's date: it drops out of the pop-up, “More from us” and the list above.
  11. Set “How often” to Once per day: “New browser session” does not bring it back, “Next day” does.
  12. With a pop-up open press the browser Back button — it closes (history-entry approach).
  13. Order status (existing screen, all 8 states): place an order, then use the Counter simulator: claim it, place it (#number), let the timer run out (→ “Checking…” → Expired, polling stops), delete the request, break the network and reload the page.
  14. Cart-changed dialog: add an item, go to Admin → Items, change its price (✎) or hide it (👁), Publish, return and Place Order.
  15. Admin CRUD: add / edit / hide / delete sections and items (a section with items can't be deleted), reorder, bulk import (pick a pretend file), Publish banner, dashboard counts, Settings validation (expiry 1–25), logo.
  16. Order link on the menu: place an order, then use “Place another order” or reload the page: a slim “Order code … · Show code ›” bar stays on the menu while the request is pending, claimed or confirmed (✕ hides it; “Pretend 3 hours passed” removes it). The cart also survives a reload.
  17. Discard changes: Admin → Items, edit something, then use Discard in the orange Publish bar (it shows the change count).
  18. Start over: “⟲ Reset everything” reloads the prototype with all data back to its original state (cart, orders, admin edits, switches).
  19. See a promotion: click “Show Timber and Tales now” (or “Show Artistry now”). It also shows in “More from us” (chip at the end of the chips, and the card at the bottom of the menu), in “While you wait” after you place an order, and in the closed-café card (Café closed preset).
  20. Roles and sign-in: switch Owner / Manager / Staff and “Signed out / not an admin” in the side panel and see what each can do.
  21. Menu load / time / splash: “Menu load” = fails or not published; “Café time” moves item time windows (Matcha Latte is 17:00–22:00); “Flutter never boots” shows the 12 s safety net; “Open an order-status link cold” shows the spinner splash.
